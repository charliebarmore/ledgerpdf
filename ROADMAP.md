- **OCR for scanned pages — ✅ WORKING, NOT YET SHIPPABLE 2026-08-04.** Closes the gap that made the tie-out layer blind on the documents preparers most want help with. `binder_read_page`/`binder_find` take `ocr:true`; a rasterized copy of fixture_a gives ground truth, and every figure reads correctly at 92.9% average confidence with boxes that land on the ink — so a figure read off a scan can be ticked where it sits, proven end to end. **Two rules held as non-negotiable:** OCR is labelled a machine reading everywhere it surfaces and carries per-word confidence (a misread digit reaching a tie-out is worse than no reading, because it is wrong confidently); and a page that already has text is never OCR'd. **Platform-native first:** macOS Vision is now the preferred backend — on-device, **nothing to bundle, sign or notarize**, every figure at confidence 1.000 in 0.49s against tesseract's 92.9% in ~2-3s — with tesseract kept as the portable fallback and the engine reported alongside every reading. Vision needed real care: it is line-oriented (per-word boxes come from `boundingBoxForRange`) and its coordinates are **bottom-left origin, y up**, the opposite of everything else here, which would put a tick at the mirror image of the figure. Guarded by asserting both engines place the same figure within 0.02 — they agree to 0.0016 — the same independent-implementation logic as the pdfium+poppler viewer conformance. **Still open: Windows.** `Windows.Media.Ocr` is the equivalent but reports **no per-word confidence**, so it cannot honour the confidence rule; either accept and surface that, or ship tesseract on Windows (~15-40 MB plus signing a second native binary). **Bundling is now a Windows-only question — macOS needs nothing shipped.**
- **Spreadsheets as binder pages — ✅ DONE 2026-08-04.** Closes the biggest gap against "bring in the documents I actually have": Excel IS the workpaper format, and until now an `.xlsx` could not enter a binder at all. `.xlsx`/`.xlsm`/`.csv` import like any source, each worksheet becoming pages built in memory at export — the untouched-source invariant holds. **Cells are really drawn with a font, so the ordinary text extraction reads them exactly** — a figure off a trial balance is addressable and tickable with no OCR in the path, proven end to end through the agent. Deliberate trade: we lay the grid out ourselves rather than bundling a 500 MB office suite, so this renders the DATA, not Excel's print layout (no merged-cell art, conditional formatting or charts — print those to PDF first). Courier chosen so column fitting is exact arithmetic rather than a font-metrics table, and figures align as an accountant reads them. **Uncalculated formulas are shown as formulas and warned about** rather than left blank, because a blank where a number belongs is the worst outcome in a workpaper. **One sheet is one page whenever it can still be read** — the largest type that fits everything on a single page is found first, and the page shape is chosen per sheet (a tall register goes portrait, a wide trial balance landscape). Fixing the orientation is what turned a real 86-row register into a full page plus a 13-row orphan. Below ~4.5pt it paginates instead, because two readable pages beat one nobody can read; wide sheets then split onto continuation pages rather than truncating. Caught in build: grouping text lines by box BOTTOM split a row in two whenever a cell had a descender — grouping by box TOP is stable.

- **Links and strikethrough in typeset memos — ✅ DONE 2026-08-06.** Two markdown constructs reached `_inline` in `documents.py` and vanished, which is the exact failure the module's own glyph-safety comment calls unacceptable: wrong, and not visibly wrong. **Strikethrough** was the worse one — the parser has it enabled (`.enable("strikethrough")`) but no `s_open`/`s_close` branch existed, so `~~cleared~~` rendered as ordinary text and an item struck off an open-items list read as still open, the same meaning-loss as `☑`/`☐` both arriving as `■`. **Links** dropped the URL and kept the text, so a memo cited a source the page could not reach. Link ink is a document blue, deliberately not a brand token, per DESIGN.md's "the brand stops at the chrome."

- **AI tie-out layer — ✅ FIRST CUT DONE 2026-08-04.** `binder_tie` checks a figure on one page against another; `binder_foot` adds a column against its stated total. **The agent decides what should tie; the tool does the arithmetic and leaves the evidence** — ticks and cross-references when things agree, notes carrying the difference and open-item flags when they do not, and a tape showing every addend so a sum is checkable rather than asserted. A model doing money arithmetic is exactly where it should not be trusted. `parseMoney` reads in whole cents and handles what a workpaper actually writes — `(350.67)` is a negative, which the tape's own parser reads as nothing — and REFUSES anything ambiguous, because a figure guessed wrong in a tie-out does not fail, it agrees confidently.
